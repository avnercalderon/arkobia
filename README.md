# פיקוח תל אביב – נהלים ורשימות תיוג (אייפד)

## קבצים
- `index.html` – האפליקציה (עיצוב ולוגיקה). לא צריך לגעת לשינויי תוכן.
- `data.js` – **כל התוכן**: תפריטים, רשימות תיוג, דפי מידע, טלפונים, קישור לסע"מ. כאן עורכים.
- `img/` – תמונות (מפות, צילומי מסך) שחולצו מהמצגת.
- `sw.js` – מאפשר עבודה ללא רשת (נטען רק ב-HTTPS, כלומר אחרי פריסה ב-Vercel).
- `icon.png` – אייקון למסך הבית.

## פריסה
להעלות את התיקייה כמו שהיא ל-GitHub → Vercel. בעת עדכון תמונות – להוסיף את שם הקובץ לרשימה ב-`sw.js` ולהעלות את `VERSION`.

## באייפד
ספארי → שיתוף → "הוסף למסך הבית". נפתח כאפליקציה ללא סרגל כתובת.
הסימונים ברשימות התיוג נשמרים מקומית במכשיר (localStorage).

## עריכת תוכן (data.js)
בראש הקובץ יש הסבר על סוגי הפריטים. דוגמאות:
- להוסיף פריט לרשימת תיוג: להוסיף מחרוזת במערך `items`.
- פריט עם תת-שורות: `{ t: "כותרת", sub: ["שורה", "שורה"] }`
- הערה ללא תיוג: במערך `notes`.
- קישור לדרייב: `{ type: "link", title: "...", url: "https://..." }`
- כל `id` חייב להיות ייחודי.
